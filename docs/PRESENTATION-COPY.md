# Shared Romanian presentation copy

`src/lib/presentation-copy.ts` holds the owner's approved section titles and
contact text. Sample, preview and public pages in all three designs use the same
copy, including pages with older saved AI headings. The PDF uses the shared
headings too. These common titles are fixed; listing descriptions, facts,
photograph captions and the other editable sections retain their saved content.
No database migration or paid text regeneration is needed to update a published
page. The closing invitation uses that property's actual address.

Only spelling, grammar and diacritics have been corrected in the supplied copy.
Future generated descriptions retain the existing factual, restrained Romanian
voice, with explicit examples of ornamental adjectives to avoid.
